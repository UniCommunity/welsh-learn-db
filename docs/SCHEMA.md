# Schema

The project ships two representations of the same content:

1. **JSON sources of truth** in `data/` — easy to edit and review in PRs.
2. **SQLite** generated by `python -m src.welsh_db load` — easy to query.

## Tables

| Table | Purpose |
| --- | --- |
| `vocabulary` | Lemmas with gloss, POS, gender, topic, level, pronunciation hint |
| `phrases` | Ready-to-use utterances with register and region tags |
| `lessons` | Suggested study path; JSON columns for lists |
| `grammar_topics` | Short grammar notes; full original object stored in `body_json` |

JSON-only files (not loaded into SQL by default):

- `data/alphabet.json`
- `data/mutations.json`
- `data/numbers.json`

Extend `src/welsh_db.py` if you want those in tables too.

## IDs

Stable string IDs (`v001`, `p001`, `L01`, `g-vso`) so downstream flashcard apps can pin items.

## Levels

Aligned loosely with Dysgu Cymraeg / Learn Welsh adult levels:

- `entry` — Mynediad / A1
- `foundation` — Sylfaen / A2
- `intermediate` — Canolradd / B1 (placeholder; expand the dataset)

## Conventions

- `cy` is the Welsh form; `en` is a short English gloss, not a full dictionary definition.
- Gender is only stored on nouns.
- Pronunciation strings are learner respellings, not IPA.
- Region is `north`, `south`, or `all`.
