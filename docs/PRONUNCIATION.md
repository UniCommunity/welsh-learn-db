# Pronunciation starter

Welsh spelling is regular once you know the extra letters. Stress is almost always on the **penultimate** syllable (`Cym-ru`, `Caer-dydd` is an exception pattern in compounds — learn common place names by ear).

## Letters that surprise English speakers

| Letter | Aim for |
| --- | --- |
| **c** | always /k/ (`cath`) |
| **f** | /v/ (`afal`) |
| **ff** | /f/ (`ffordd`) |
| **dd** | voiced *th* as in *this* |
| **th** | voiceless *th* as in *thin* |
| **ch** | as in Scots *loch* |
| **ll** | voiceless *l*: tongue in an *l* position, blow air around the sides |
| **rh** | voiceless / trilled *r* |
| **w** | vowel /u/ (`cwrw`) or glide |
| **u** | South Wales ≈ *ee*; North Wales is a distinct central vowel |
| **y** | clear *ee/i* in final syllables; obscure *uh* in many unstressed syllables (`y`, `yn`, `Cymru`) |
